## 📖 About the Project

**Contact Book** is a simple and functional web application that allows users to create, store, and search for contacts easily.  
All contacts are saved locally using the **Local Storage API**, ensuring your data remains even after closing the browser.

🔗 **Access the live project:** [Click here](https://alexwalkergd.github.io/Contact-book/)

## 🚀 Features

- 📝 Add new contacts with name and phone number
- 🔍 Search for contacts by name
- 💾 Automatic saving using Local Storage
- 📱 Fully responsive design

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript
- Local Storage API

## ⚙️ How to Run Locally

1. Clone this repository:

    ```bash
   git clone https://github.com/alexwalkergd/Contact-book.git
    ```

2. Access the project folder:

    ```bash
   cd Contact-book
    ```

3. Open the `index.html` file directly in your browser  
   *(or use a VS Code extension like “Live Server” to run it locally)*
